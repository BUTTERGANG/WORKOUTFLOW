# WorkoutFlow

A full-stack workout tracking application for coaches and athletes. Organizations create teams, coaches build multi-week training programs from an exercise library and assign them to athletes, and athletes log workouts (sets, reps, weight) and track progress over time. It also includes in-app messaging, habit tracking, and join-request/invite flows for organizations and teams.

## Tech Stack

**Backend**
- Node.js + Express (TypeScript)
- Drizzle ORM with PostgreSQL (via `@neondatabase/serverless`, WebSocket-based driver)
- Session auth with Passport (`passport-local`), `express-session` + `connect-pg-simple` (Postgres-backed sessions), `bcryptjs` for password hashing
- Security middleware: `helmet`, CSRF protection (`csrf-csrf`), rate limiting, input sanitization (`sanitize-html`)

**Frontend**
- React 18 + TypeScript, built with Vite
- Routing via `wouter`
- Data fetching/caching via `@tanstack/react-query`
- UI built on Radix UI primitives + Tailwind CSS (shadcn/ui-style components)
- Charts via `recharts`, forms via `react-hook-form` + `zod`

**Shared**
- `shared/schema.ts` defines the Drizzle schema and Zod validation, imported by both client and server.

## Directory Structure

```
client/               React frontend (Vite root)
  src/pages/           Route-level pages (dashboard, workout, programs, athletes, progress, messages, settings, auth, onboarding, etc.)
  src/components/      Shared components, incl. shadcn/ui components under src/components/ui
  src/contexts/        React context providers (e.g. AppContext)
  src/hooks/           Custom hooks (auth, toast, mobile detection)
  src/lib/             Client utilities (query client, auth/role helpers)

server/               Express backend
  index.ts             App entrypoint, middleware setup, dev/prod bootstrapping
  routes.ts            All REST API route handlers (/api/...)
  localAuth.ts          Passport local-auth + session configuration
  db.ts                 Drizzle/Postgres connection setup
  storage.ts            Data access layer used by routes
  middleware/           CSRF, rate limiting, sanitization, authorization
  seed.ts, seedAllExercises.ts   Database seeding scripts

shared/
  schema.ts            Drizzle table definitions + Zod schemas shared by client and server (users, organizations, teams, exercises, programs, program weeks/days/exercises, program assignments, workout sessions, exercise/set logs, messages, habit trackers, password reset tokens, audit logs, etc.)

migrations/            SQL migrations generated by drizzle-kit
```

The app is served as a single Express process: in development, Express mounts Vite's dev middleware for the client; in production it serves the built static client and bundled server from `dist/`.

## Setup

### Prerequisites
- Node.js and npm
- A PostgreSQL database (the project uses the Neon serverless driver, but any Postgres instance reachable via a connection string works)

### Environment variables

There is no `.env.example` in the repo; create a `.env` (or otherwise set these) with:

| Variable | Required | Description |
|---|---|---|
| `DATABASE_URL` | Yes | PostgreSQL connection string used by Drizzle and by the session store |
| `SESSION_SECRET` | Yes | Secret used to sign session cookies |
| `CSRF_SECRET` | Yes | Secret used by the CSRF protection middleware |
| `PORT` | No (default `5000`) | Port the Express server listens on (serves both API and client) |
| `NODE_ENV` | No | `development` or `production`; affects session cookie security and whether Vite dev middleware is used |
| `LOG_LEVEL` | No | Controls server log verbosity |

### Install

```bash
npm install
```

### Database setup

Push the Drizzle schema (`shared/schema.ts`) to your database:

```bash
npm run db:push
```

Optionally seed the exercise library and sample data:

```bash
npx tsx server/seedAllExercises.ts
npx tsx server/seed.ts
```

## Running in Development

```bash
npm run dev
```

This starts the Express server (`server/index.ts` via `tsx`) with Vite's dev middleware attached, serving the React client and the `/api/*` REST endpoints from the same process on `http://localhost:5000` (or `$PORT`).

## Build & Run in Production

```bash
npm run build   # Vite build for client + esbuild bundle for server -> dist/
npm start        # NODE_ENV=production node dist/index.js
```

## Other Scripts

- `npm run check` — TypeScript type-check (`tsc`)
- `npm run db:push` — apply the Drizzle schema to the configured database
