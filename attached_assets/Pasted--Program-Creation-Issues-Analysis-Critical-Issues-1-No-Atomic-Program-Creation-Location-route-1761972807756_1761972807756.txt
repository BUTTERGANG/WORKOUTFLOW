🔍 Program Creation Issues Analysis
🔴 Critical Issues
1. No Atomic Program Creation
Location: routes.ts - Program creation endpoints
typescript// Creating a program with weeks/days/exercises requires MULTIPLE API calls
POST /api/programs              // Create program
POST /api/programs/:id/weeks    // Add week (separate call)
POST /api/weeks/:id/days        // Add day (separate call)
POST /api/days/:id/exercises    // Add exercise (separate call)
Problem: If any step fails, you get a partial program. No rollback mechanism.
Example failure scenario:

Program created ✅
Week 1 created ✅
Day 1 created ✅
Exercise 1 fails ❌
Result: Orphaned program with incomplete structure

Fix: Use database transactions:
typescriptapp.post('/api/programs/complete', async (req, res) => {
  await db.transaction(async (tx) => {
    const program = await tx.insert(programs).values(...).returning();
    const weeks = await tx.insert(programWeeks).values(...).returning();
    const days = await tx.insert(programDays).values(...).returning();
    const exercises = await tx.insert(programExercises).values(...).returning();
    return program;
  });
});

2. N+1 Query Nightmare in getProgramWeeks
Location: storage.ts line ~370
typescriptasync getProgramWeeks(programId: string): Promise<any[]> {
  const weeks = await db.select()... // 1 query
  
  const weeksWithDays = await Promise.all(
    weeks.map(async (week) => {
      const days = await db.select()... // N queries (12 for 12 weeks)
      
      const daysWithExercises = await Promise.all(
        days.map(async (day) => {
          const exercisesData = await db.select()... // M queries (60 for 5 days/week)
        })
      );
    })
  );
}
Total Queries: 1 + 12 + (12 × 5) = 73 database queries for one program!
Fix: Use JOINs:
typescriptasync getProgramWeeks(programId: string) {
  return await db
    .select({
      week: programWeeks,
      day: programDays,
      exercise: programExercises,
      exerciseDetails: exercises,
    })
    .from(programWeeks)
    .leftJoin(programDays, eq(programWeeks.id, programDays.weekId))
    .leftJoin(programExercises, eq(programDays.id, programExercises.dayId))
    .leftJoin(exercises, eq(programExercises.exerciseId, exercises.id))
    .where(eq(programWeeks.programId, programId))
    .orderBy(programWeeks.weekNumber, programDays.dayNumber, programExercises.order);
  
  // Then group in memory (1 query instead of 73!)
}

4. Missing Cascade Deletes
Location: Schema definition
Problem: If you delete a program, orphaned data remains:
typescriptDELETE /api/programs/:id

// Program deleted ✅
// But weeks still exist ❌
// And days still exist ❌
// And exercises still exist ❌
Fix: Add cascade in schema or manual cleanup:
typescriptasync deleteProgram(id: string): Promise<void> {
  await db.transaction(async (tx) => {
    // Get all weeks
    const weeks = await tx.select().from(programWeeks).where(eq(programWeeks.programId, id));
    
    // Get all days
    const weekIds = weeks.map(w => w.id);
    const days = await tx.select().from(programDays).where(inArray(programDays.weekId, weekIds));
    
    // Delete in correct order
    const dayIds = days.map(d => d.id);
    await tx.delete(programExercises).where(inArray(programExercises.dayId, dayIds));
    await tx.delete(programDays).where(inArray(programDays.id, dayIds));
    await tx.delete(programWeeks).where(inArray(programWeeks.id, weekIds));
    await tx.delete(programs).where(eq(programs.id, id));
  });
}

typescriptasync createProgramExercise(exerciseData: InsertProgramExercise): Promise<ProgramExercise> {
  // If no order provided, auto-calculate
  if (!exerciseData.order) {
    const lastExercise = await db
      .select()
      .from(programExercises)
      .where(eq(programExercises.dayId, exerciseData.dayId))
      .orderBy(desc(programExercises.order))
      .limit(1);
    
    exerciseData.order = (lastExercise[0]?.order || 0) + 1;
  }
  
  // Check for duplicate order
  const duplicate = await db
    .select()
    .from(programExercises)
    .where(
      and(
        eq(programExercises.dayId, exerciseData.dayId),
        eq(programExercises.order, exerciseData.order)
      )
    )
    .limit(1);
  
  if (duplicate.length > 0) {
    throw new ConflictError('An exercise with this order already exists');
  }

  return exercise;
}
