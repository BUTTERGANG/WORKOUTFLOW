# Weightlifting Team Management Platform

A comprehensive workout programming platform for weightlifting coaches and athletes. Create programs, track workouts, manage teams, and monitor athlete progress.

## 🏋️ Features

### For Coaches
- **Program Builder**: Create structured training programs with weeks, days, and exercises
- **Team Management**: Organize athletes into teams and manage memberships
- **Athlete Tracking**: Monitor athlete progress and workout completion
- **Exercise Library**: Access 193+ pre-loaded weightlifting exercises or create custom ones
- **Program Assignment**: Assign training programs to individual athletes
- **Join Request Management**: Approve or reject athlete team join requests

### For Athletes
- **Workout Logging**: Log sets, reps, weight, and RPE for each exercise
- **Progress Tracking**: View personal records and training history
- **Team Search**: Find and join teams
- **Mobile-Optimized**: Responsive workout interface for gym use
- **Rest Timer & Plate Calculator**: Built-in training tools

## 🚀 Quick Start

### Prerequisites

- **Node.js** 20+ (LTS recommended)
- **PostgreSQL** 16+ (or NeonDB account)
- **npm** or **pnpm**

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd REPLIT
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   ```

   Edit `.env` and add your configuration:
   ```env
   DATABASE_URL=postgresql://user:password@host:port/database
   SESSION_SECRET=your-secret-key-min-32-characters
   REPL_ID=your-replit-id
   NODE_ENV=development
   PORT=5000
   ```

4. **Initialize the database**
   ```bash
   npm run db:push
   ```

5. **Seed the exercise library** (optional but recommended)
   ```bash
   npm run seed
   ```

6. **Start the development server**
   ```bash
   npm run dev
   ```

   The app will be available at `http://localhost:5000`

## 🗄️ Database Schema

The application uses PostgreSQL with Drizzle ORM. Key tables include:

- **users**: User accounts and profiles
- **organizations**: Coaching businesses
- **teams**: Groups of athletes within organizations
- **exercises**: Exercise library (global + custom)
- **programs**: Training programs with hierarchical structure
  - program_weeks
  - program_days
  - program_exercises
- **workout_sessions**: Athlete workout logging
  - exercise_logs
  - set_logs
- **messages**: Coach-athlete communication (coming soon)

See `shared/schema.ts` for complete schema definition.

## 🚢 Deployment

### Deploying to Replit

1. **Set environment variables** in Replit Secrets:
   - `DATABASE_URL`: Your NeonDB connection string
   - `SESSION_SECRET`: Random 32+ character string
   - `REPL_ID`: Provided by Replit
   - `NODE_ENV`: Set to `production`

2. **Run migrations**:
   ```bash
   npm run db:push
   ```

3. **Seed exercises** (first time only):
   ```bash
   npm run seed
   ```

4. **Deploy**: Replit will automatically build and deploy

### Deploying Elsewhere

1. Build the application:
   ```bash
   npm run build
   ```

2. Set environment variables on your hosting platform

3. Run database migrations:
   ```bash
   npm run db:push
   ```

4. Start the production server:
   ```bash
   npm start
   ```

## 📚 API Documentation

### Authentication Endpoints

- `GET /api/auth/user` - Get current user
- `POST /api/auth/register` - Complete registration
- `GET /api/login` - Initiate OAuth login
- `GET /api/logout` - Logout

### Organizations

- `POST /api/organizations` - Create organization
- `GET /api/organizations/my` - Get user's organizations
- `GET /api/organizations/:id` - Get organization by ID
- `PATCH /api/organizations/:id` - Update organization
- `DELETE /api/organizations/:id` - Delete organization

### Teams

- `POST /api/teams` - Create team
- `GET /api/teams/search?q=query` - Search teams
- `GET /api/organizations/:orgId/teams` - Get org teams
- `DELETE /api/teams/:id` - Delete team

### Programs

- `POST /api/programs` - Create program
- `GET /api/organizations/:orgId/programs` - Get org programs
- `GET /api/programs/:id` - Get program details
- `PATCH /api/programs/:id` - Update program
- `DELETE /api/programs/:id` - Delete program
- `POST /api/programs/complete` - Create complete program with weeks/days/exercises

For complete API documentation, see the inline comments in `server/routes.ts`.
